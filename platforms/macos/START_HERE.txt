1132.WTF 1.0.12 — Mac only
==========================

This app wipes the old Zoom identity, then opens Zoom.app.
It does not open a web page.

Download the zip:

https://github.com/domnsea/ZOOM.WTF/releases/latest/download/1132.WTF-macos-1.0.0.zip

Delete the old zip first. Double-click the new zip. Double-click 1132.WTF.app.

The window title must say 1132.WTF 1.0.12. If it does not, you still have the old app.

STEP 1 - Click STEP 1 - Fix Zoom
STEP 2 - Type Guest. Type the meeting number.
LAUNCH - Click LAUNCH. Zoom.app opens. Click Join. Paste the meeting number.

If macOS will not replace the old app in Applications, paste this in Terminal:

sudo rm -rf /Applications/1132.WTF.app && sudo cp -R "$HOME/Downloads/1132.WTF-macos-1.0.0/1132.WTF.app" /Applications/1132.WTF.app && sudo chown -R "$(whoami):staff" /Applications/1132.WTF.app && xattr -cr /Applications/1132.WTF.app && open /Applications/1132.WTF.app
