1132 FRESH 1.0.21 — Mac only
============================

The new name worked. 1132 stayed because Zoom is still
seeing this network (public IP) and this Mac.

1.0.21 randomizes the Wi-Fi MAC and the computer name
for this session, then puts them back when you quit Zoom.

It cannot rewrite the logic-board serial. If 1132 stays,
connect a phone hotspot or a VPN before you click Join.
Same home/work IP = same 1132.

The lime banner must say 1132 FRESH 1.0.21.
If it does not, you have the old app. Trash it.

Download:

https://github.com/domnsea/ZOOM.WTF/releases/latest/download/1132-FRESH-macos.zip

STEP 1 - Right-click "STEP 1 - OPEN FRESH ZOOM.command" → Open → Open
         Type your Mac password. When it asks, switch to a hotspot or VPN.
STEP 2 - Zoom Join must show the random name, not your Mac login.
LAUNCH - If you still get 1132, you are still on the blocked IP.

If macOS will not replace the old app in Applications:

sudo rm -rf /Applications/1132.WTF.app && sudo cp -R "$HOME/Downloads/1132-FRESH-macos/1132.WTF.app" /Applications/1132.WTF.app && sudo chown -R "$(whoami):staff" /Applications/1132.WTF.app && xattr -cr /Applications/1132.WTF.app && open /Applications/1132.WTF.app
