1132 FRESH 1.0.16 — Mac only
============================

This zip is named 1132-FRESH-macos.zip
The icon is LIME GREEN, not cyan.
The window title is 1132 FRESH.
The lime banner says 1132 FRESH 1.0.16.
The Dock name is 1132 FRESH.

If you do not see 1.0.16, you have the old app. Trash it.

Each LAUNCH picks a new random Zoom name (for example Riley Kim 042)
so the last name cannot be reused.

LAUNCH also creates a hidden temporary Mac user, then starts Zoom with
launchctl asuser + sudo -u as THAT user. When you quit Zoom, that user
is deleted.

Download:

https://github.com/domnsea/ZOOM.WTF/releases/latest/download/1132-FRESH-macos.zip

Delete every old 1132 zip. Double-click 1132-FRESH-macos.zip.
Double-click 1132.WTF.app. The window must say 1132 FRESH 1.0.16.

STEP 1 - Click STEP 1 - Fix Zoom
STEP 2 - A random name is already in the box. Type the meeting number.
LAUNCH - Click LAUNCH. Type your Mac password when asked. Zoom opens as
         the temporary user with that new name. Click Join. Paste the
         meeting number. When you quit Zoom, that temporary user is deleted.

If macOS will not replace the old app in Applications, paste this in Terminal:

sudo rm -rf /Applications/1132.WTF.app && sudo cp -R "$HOME/Downloads/1132-FRESH-macos/1132.WTF.app" /Applications/1132.WTF.app && sudo chown -R "$(whoami):staff" /Applications/1132.WTF.app && xattr -cr /Applications/1132.WTF.app && open /Applications/1132.WTF.app
