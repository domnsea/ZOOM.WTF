1132 FRESH 1.0.20 — Mac only
============================

1.0.19 opened Zoom as a throwaway user with no login
keychain. Zoom then said "A keychain cannot be found to
store Zoom", quit, and your regular dustin profile
reopened.

1.0.20 creates that keychain first, waits until throwaway
Zoom stays up, and if it dies it restores your regular
Zoom and keeps it closed so the login profile cannot pop
back open.

The lime banner must say 1132 FRESH 1.0.20.
If it does not, you have the old app. Trash it.

Download:

https://github.com/domnsea/ZOOM.WTF/releases/latest/download/1132-FRESH-macos.zip

STEP 1 - Right-click "STEP 1 - OPEN FRESH ZOOM.command" → Open → Open
         Type your Mac password when asked.
STEP 2 - Zoom Join must show the random name, not your Mac login.
LAUNCH - Quit Zoom when done, or run STEP 2 - CLOSE AND CLEAN ZOOM.command

If macOS will not replace the old app in Applications:

sudo rm -rf /Applications/1132.WTF.app && sudo cp -R "$HOME/Downloads/1132-FRESH-macos/1132.WTF.app" /Applications/1132.WTF.app && sudo chown -R "$(whoami):staff" /Applications/1132.WTF.app && xattr -cr /Applications/1132.WTF.app && open /Applications/1132.WTF.app
